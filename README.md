# 🎯 CS Command Center OS
A modular Desktop Operating System for Client Success Professionals.

## ✨ Features
- **Live Revenue Tracking:** Real-time data from Google Sheets (Subscription vs Top-ups).
- **Smart Calendar:** Categorized office schedule (Onboarding, Training, Issues).
- **AI Strategy Hub:** Gemini 1.5 Flash powered reporting.
- **Task Management:** Local persistence for daily action items.

## 🛠️ Tech Stack
- Python 3.12 (CustomTkinter)
- Google Cloud APIs (Sheets, Calendar)
- Google Generative AI (Gemini)
